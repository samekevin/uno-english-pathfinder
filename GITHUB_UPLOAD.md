# GitHub upload instructions

## Recommended repository

Create a new GitHub repository for the Pathfinder project. A simple name such as `uno-english-pathfinder` is sufficient.

## Upload

Upload the **contents of this packet**, not the outer ZIP file as a single repository file.

The repository root should contain:

- `README.md`
- `FREEZE.md`
- `GITHUB_UPLOAD.md`
- `data/`
- `tests/`
- `docs/`
- `schemas/`
- `reference/`

Do not upload macOS `__MACOSX` folders or `.DS_Store` files.

## After upload

The first GitHub milestone is only to freeze and review the source data. Do not turn on a public GitHub Pages site until the web prototype exists and the privacy/contact flow has been reviewed.

## Suggested next commit

`build: add Pathfinder v1.3 web prototype`

That commit should add the application, scoring engine, automated tests, and a GitHub Pages deployment workflow.
